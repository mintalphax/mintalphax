## 🧰 Tools · 工具

### [healthsvc](https://github.com/mintalphax/healthsvc)

Scheduled screen-lock for parental control — locks the screen at configured
times using **NTP-verified time**, so changing the system clock cannot bypass
the schedule. Trigger-file architecture with a privileged daemon and a
per-user lock component.
